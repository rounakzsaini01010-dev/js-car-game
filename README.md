# 🚗 JS Car Game

A simple **2D Car Racing Game** developed using **HTML, CSS, and JavaScript**. The game runs directly in the web browser and provides an interactive racing experience where the player controls a car and avoids obstacles.

## 🎮 Game Overview

In this game, the player controls a car on a racing track. Enemy cars/obstacles appear on the road, and the player needs to move the car and avoid collisions.

The game is designed as a lightweight browser-based project to demonstrate **JavaScript game logic, keyboard controls, animations, collision detection, and dynamic gameplay**.

## ✨ Features

* 🚘 Player car movement
* 🛣️ Racing road/track
* 🚗 Moving enemy cars
* 🎮 Keyboard-based controls
* 💥 Collision detection
* 🏆 Score tracking
* 🔄 Dynamic gameplay
* 🌐 Browser-based gameplay
* ⚡ No external framework required

## 🎮 Controls

Use the keyboard to control the car during gameplay.

* ⬅️ **Left Arrow** – Move Left
* ➡️ **Right Arrow** – Move Right
* ⬆️ **Up Arrow** – Move Up
* ⬇️ **Down Arrow** – Move Down

> Controls may vary depending on the current game implementation.
